# ESP32 Wi-Fi RC Car

A Wi-Fi controlled RC car built using an ESP32, L298N motor driver, DC motors, and an SG90 servo motor.

## Project Overview

This is my first completed electronics and embedded systems project.

The car is controlled wirelessly using an ESP32 over Wi-Fi. It uses an L298N motor driver to control the two DC motors and an SG90 servo motor for steering.

## Components Used

- ESP32
- L298N motor driver
- 2 × DC motors
- SG90 servo motor
- 2 × 18650 Li-ion cells
- RC car chassis and wheels
- PCB
- DC-DC buck converter

## Features

- Wi-Fi-based wireless control
- Forward and reverse movement
- Left and right steering
- Separate motor and steering control
